# 3D Tactical Turn-Based Kingdom
A prototype of a 3D tactical game built with Unity.  
The project demonstrates core gameplay systems for a turn-based hexagonal battlefield combined with an open world approach.

Key features:
- Hex-based pathfinding with verticality (movement and abilities depend on height levels)
- Open-world oriented: the world is not split into locations and can be infinitely expanded
- Flexible camera system inspired by strategy games like Civilization VI:
  - Move, rotate and zoom freely
  - When zoomed in, the camera focuses on the character
  - When zoomed out, the perspective gradually shifts into a top-down tactical view
- Character progression with a simple leveling system
- Upgrade system for character abilities
- Enemy AI built on a state machine (patrolling, attacking, idle states)
- Turn-based combat mechanics (prototype level)
